# 界面调校台

在对话里给出打开入口。

`[界面调校台](sidecar://antigravity-ui-tweaks/theme/)`

- 主题先在面板内预览。检测并选择渲染窗口后才能临时应用、查询令牌或截图。配置种子只在用户选择写入时保存。
- 会话工具可以跳转、查看时间线、导出 Markdown 或打开文件。Active workspace 规则可由面板读取和更新调校台自己的 AGENTS.md 片段。
- MCP、任务、Hooks、REA 提供本地诊断。实际连接、创建会话、截图、审计启用和文件写入都由用户在对应入口触发。插件与内置组件的启停只给宿主开关，独立规则要用户确认「离线停用」才改名。
- Hooks 审计只记录 `SessionStart` 与 `PostToolUse`，不订阅 `PreToolUse`，任何情况下都不改动权限决定。
- 渲染行为和内部令牌会随宿主更新，以目标窗口探针和实际显示结果为准。探测会把未收录令牌并入调色板；宿主切换主题时面板自动撤掉注入的临时样式。
